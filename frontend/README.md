# Meridian — Project Intelligence UI

This is the Meridian web app (React + Vite + Tailwind 4 + Radix UI). It talks to the Meridian API (`/backend`) for workspaces, projects, and items.

## Run

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # output in dist/
```

Set `VITE_API_URL` at build time to your API URL, or use `?api_url=...` in the browser.
